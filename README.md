To run the program, navigate to src/neural_networks and type python main.py in the terminal. All four models will run sequentially. For each model, after training and evaluation, the confusion matrix map will pop up, followed by the training loss vs. epoch curve, and finally followed by the accuracy curve. To continue with the script, exit out of each figure, and the script will continue. This is repeated for all four models.
